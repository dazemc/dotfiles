# Archive

Unused configuration kept for reference. Nothing here is linked, sourced, or
autostarted; `setup.sh`, `restore.sh`, and `diagnose.sh` never read it, and the
live session does not depend on it.

Moving something out of the archive is a reviewed step, not a copy: restore the
path, re-add its links to `setup.sh` (and the map in `.llm/structure.md`),
verify in the live session, then commit the config and the docs separately.

Current contents:

- `quickshell/` — retired QML bar. Trickster is the live bar; do not extend
  this tree or wire it into autostart.
